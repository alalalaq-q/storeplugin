# 电商图片提取下载器（Chrome 扩展）

在淘宝、京东、拼多多商家版商品详情页一键提取所有商品图片，并在新页面中勾选、批量下载为 PNG 格式。

## 安装

1. 打开 Chrome，地址栏输入 `chrome://extensions` 回车。
2. 打开右上角「开发者模式」开关。
3. 点击「加载已解压的扩展程序」，选择本目录（`ecommerce-image-extractor`）。
4. 安装完成后，无需点击工具栏图标，直接前往商品详情页使用。

## 使用

1. 打开任意商品详情页（淘宝 / 天猫 / 京东 / 拼多多商家版）。
2. 页面右下角会出现悬浮按钮「获取图片」。
3. 点击后，扩展会扫描页面所有商品图片，并在新标签页中展示。
4. 在结果页勾选需要下载的图片（支持全选 / 全不选 / 反选）。
5. 点击「下载选中」，图片会统一转换为 PNG 并保存到浏览器默认下载目录。
   - 文件名规则：`商品名_001.png`、`商品名_002.png` …（序号补零）。

## 权限说明

- `activeTab` / `scripting`：在详情页注入按钮与脚本。
- `downloads`：保存图片到下载目录。
- `storage`：在后台与结果页之间传递图片列表。
- `host_permissions`：覆盖三大平台页面及其常见图片 CDN 域名，用于跨域抓取并转换图片。

## 已知限制

- 若某张图片所在 CDN 域名未被 `host_permissions` 覆盖，跨域抓取可能失败。遇到这种情况，请把该图片的域名以 `*://*.域名/*` 形式追加到 `manifest.json` 的 `host_permissions` 后重新加载扩展。
- 若图片服务器有防盗链（校验 Referer），转换可能失败，属平台限制。
- 动图（GIF / WebP 动画）会被转换为静态首帧 PNG。

## 可选：添加图标

如需自定义扩展图标，在 `manifest.json` 中增加：

```json
"icons": { "16": "icons/icon16.png", "48": "icons/icon48.png", "128": "icons/icon128.png" }
```

并放入对应尺寸的 PNG 文件即可。
